# currency-rate

Скрипт на Python, который получает актуальные курсы USD и EUR к рублю
с официального API Центробанка и выводит их в консоль.

## Возможности
- Запрос курсов через библиотеку `requests`
- Обработка ошибок сети и недоступности сервера

## Запуск
1. Установите зависимость: `pip install requests`
2. Запустите: `python currency-rate.py`

## Пример вывода
USD: 84.90 руб.
EUR: 94.97 руб.
